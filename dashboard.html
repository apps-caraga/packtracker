Google Sheet setup instructions
  1. Create a Google Sheet → Extensions → Apps Script.
  2. Delete the default Code.gs contents and paste the script below — use Copy Code.gs (same as google-sheet/Code.gs in this repo).
  3. Optional: set SCRIPT_SECRET in the script and the same value below. Leave both empty to test.
  4. After code changes, deploy a New version of the web app or posts may not run updated code.
  5. Run initializeSheets once (approve permissions).
  6. Deploy → New deployment → Web app: Execute as Me, access Anyone.
  7. Copy the Web app URL ending in /exec into this dashboard.
