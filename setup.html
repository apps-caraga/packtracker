Upstash Redis

Create a database at upstash.com, open REST API, copy URL and token. Counters and dashboard share the same database and key prefix.

Read-only token works for the dashboard. Counter sync and reset need write access.

Google Sheet sync

Only the Apps Script Web app URL (…/exec) is stored here — not your Google login or Sheet link.

Google Sheet setup instructions
  1. Create a Google Sheet → Extensions → Apps Script.
  2. Paste the script below (or from google-sheet/Code.gs in this repo).
  3. Optional: set SCRIPT_SECRET in the script and the same value above.
  4. Run initializeSheets once, then deploy Web app (Execute as Me, Anyone).
  5. Copy the URL ending in /exec into the field above.
